🏏 Beyond the Price Tag: A Data-Driven Analysis of IPL Auction Efficiency

Turning IPL Auction Data into Meaningful Insights

📌 Project Overview

This project explores the relationship between IPL auction spending and player performance through an interactive Power BI dashboard. It provides insights into team-wise expenditure, player acquisition strategies, auction pricing trends, and player contributions using data modelling and DAX.

🎯 Project Objectives

Analyse team-wise auction expenditure and player acquisition patterns.

Evaluate auction prices and team spending strategies.

Examine batting and bowling performance across IPL seasons.

Develop an interactive dashboard for effective data exploration and decision-making.

📊 Dashboard Components

1. Auction Overview

Explore team-wise auction expenditure, player acquisitions, and pricing patterns to understand team spending strategies.

2. Performance Analysis

Discover player contributions through batting and bowling statistics across IPL seasons.

⚡ Interactive Features

Dynamic Slicers: Explore data using interactive filters.

Bookmarks: Navigate between dashboard views seamlessly.

Drill-through: Access detailed player-level analysis.

Custom Tooltips: Discover additional insights through interactive visuals.

DAX Measures: Enable dynamic calculations and analytical comparisons.

🛠️ Tools & Technologies

Microsoft Power BI

DAX (Data Analysis Expressions)

Data Modelling

Data Visualisation

📈 Project Outcome

Successfully developed an interactive Business Intelligence dashboard that transforms IPL auction and player performance data into meaningful insights, helping explore auction efficiency, team spending patterns, and player contributions.
